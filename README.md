### 🎙️ [Voice AI Assistant](https://github.com/egorikdo/voice-ai-assistant)

**Локальный голосовой AI-ассистент с Telegram-интерфейсом и обработкой речи с помощью NLP/LLM.**

Переработанный и расширенный open-source проект с модульной архитектурой.

**Возможности:**
- Распознавание русскоязычных голосовых сообщений с помощью Vosk.
- Локальная LLM-суммаризация через Ollama и Qwen3.
- Автоматическое извлечение задач, поручений и сроков.
- Хранение истории транскрипций в SQLite.
- Экспорт истории в TXT.
- Изолированные обработчики Telegram, NLP и базы данных.
- Автоматические тесты и GitHub Actions.

**Стек:** `Python` · `aiogram 3` · `Vosk` · `FFmpeg` · `Ollama` · `Qwen3` · `SQLite` · `pytest`

**[Исходный код и документация →](https://github.com/egorikdo/voice-ai-assistant)**
